Dashboard login

Only people with an access token for this site’s GitHub repository can log in.

How to create a token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your site’s repository.
  3. Permissions → Contents: Read and write (also give Actions: Read-only so the site status can be shown).
  4. Copy the token and paste it here. GitHub shows it only once.
