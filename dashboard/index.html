Dashboard login

Sirf wahi login kar sakta hai jiske paas is site ke GitHub repo ka access token ho.

Token kaise banayein?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → apni site ka repo.
  3. Permissions → Contents: Read and write (Actions: Read-only bhi de do, site status dikhane ke liye).
  4. Token copy karke yahan paste karo. Ye sirf ek baar dikhta hai.
